## Frontend (Run Locally)
To run the frontend locally:
1. Navigate to the frontend directory: `cd frontend`
2. Install dependencies: `npm install`
3. Start the development server: `npm run dev`

You can use the frontend Settings page to upload the menu/business document and other details.

## Easy Setup (Windows)
To quickly set up the project on Windows:
1. Run `start_project.bat`. This script will:
   - Create a virtual environment
   - Install all requirements
   - Start both the backend and frontend services.
